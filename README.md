Here we provide Sage code to compute the Atkin-Lehner group of Shimura's modular curve associated to a real quadratic field of discriminant N. (See file "atkin_lehner_groups.sage".)

We also provide the computational evidence we have obtained so far, which may be found in plain text files whose name indicates the number of prime divisors of the level N. The format is described in atkin_lehner_groups.sage
